# 🏥 Hospital Management System

A web-based Hospital Management System for managing hospital records such as patients, doctors, appointments, and other medical information.

## 🌐 Live Demo

👉 [Open Hospital Management System](https://hospital-management-system-production-8339.up.railway.app)

## 💻 GitHub Repository

This repository contains the source code of the Hospital Management System.

## 🚀 Features

- Patient Management
- Doctor Management
- Appointment Management
- Add New Records
- Edit Records
- Delete Records
- Search and Filter Records
- MySQL Database Integration

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- Railway
